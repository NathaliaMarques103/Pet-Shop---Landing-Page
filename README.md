# 🐾 Pet Shop Amigo Fiel | Landing Page & Soluções para Negócios Locais

> Uma landing page moderna, responsiva e focada em conversão para pequenos negócios do setor pet, desenvolvida para unir excelência visual (HTML/CSS) e interatividade dinâmica (JavaScript).

---

## 🚀 Sobre o Projeto
O **Pet Shop Amigo Fiel** é um projeto de portfólio focado na digitalização de comércios locais. Desenvolvido para resolver uma dor real de mercado — a dificuldade que pequenos empreendedores têm em atrair clientes online e apresentar os seus serviços com clareza —, este projeto simula a presença digital completa de um estabelecimento voltado ao bem-estar animal.

Este projeto faz parte da minha jornada de desenvolvimento frontend e de estratégias voltadas a otimizar processos para PMEs (Pequenas e Médias Empresas).

---

## ✨ Funcionalidades
* **Design Responsivo e Moderno:** Estrutura limpa adaptada para computadores, tablets e telemóveis.
* **Navegação Fluida (Smooth Scroll):** Transições suaves entre as secções principais da página.
* **Integração com WhatsApp:** Botões de chamada para ação (*CTA*) direcionados para conversão direta e agendamento de serviços.
* **Botão Inteligente "Voltar ao Topo":** Componente dinâmico em JavaScript que facilita a usabilidade do utilizador em páginas longas.
* **Vitrine de Serviços:** Secções dedicadas a banho e tosa, clínica veterinária e acessórios.
* **Depoimentos de Clientes:** Prova social integrada para gerar confiança nos tutores de pets.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as tecnologias fundamentais da web sem frameworks pesados, garantindo alta performance e velocidade de carregamento:

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização avançada, uso de flexbox, variáveis, gradientes e media queries para responsividade.
* **JavaScript (Vanilla):** Lógica interativa para o botão flutuante e scroll suave.
* **Font Awesome:** Ícones vetoriais modernos.
